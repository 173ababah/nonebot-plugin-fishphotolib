# nonebot-plugin-fishphotolib 🐟

> 一个能用的图片库：**相册 / 标签 / 搜索 / 随机**，入库自动 **dHash 去重**，
> 并给出可解释的「露点 / 二次元」粗筛。**零 LLM 开销**（不接视觉模型也能跑）。

从跑了半年的 QQ 机器人（[肥鱼人设](https://github.com/173ababah)）里拆出来的图库模块。

## 命令

| 命令 | 说明 |
|------|------|
| `/图库` | 最新几张（带标签、⚠️ 标注粗筛偏露的） |
| `/图库 猫` | 按标签 / 关键词搜 |
| `/图库 随机 [标签]` | 随机发一张 |
| `/图库 标签` | 标签统计 |
| `/图库 相册` | 相册统计 |
| `/图库 加 猫 萌宠` | 超管，**回复一张图**入库（自动去重 + 粗筛） |

## 为什么用 dHash 而不是 md5

群里同一张图被转存十次，md5 十条记录、dHash 一条。dHash 只比较**相邻像素的相对亮度**，
重压缩/改尺寸之后只差 0~4 位，`FISHLIB_DHASH_DIST=6` 以内就算重复。

```
缩成 9×8 灰度 → 每行相邻像素比较 → 64 bit → 16 位十六进制
```

## 粗筛是「可解释」的，不是玄学

| 指标 | 怎么算 | 用途 |
|------|--------|------|
| `skin` | 近似 YCbCr 的暖色 + 中等亮度像素占比 | 露不露（阈值 `FISHLIB_SKIN_THRESH=0.28`） |
| `flat` | 颜色量化后最大色块占比 | 二次元/表情包（色块集中） |
| `sat` | 平均饱和度 | 插画通常更高 |

⚠️ **这只是粗筛**：真实照片的 `skin` 也可能很高。它的定位是「没接模型时先挡一道」，
真要准就开 `FISHLIB_VISION` 并给 `classify.verify_with()` 传一个识图函数：

```python
classify.verify_with(img_bytes, lambda b: {"nsfw": ..., "anime": ...})
```

**没接模型时不要默认放行** —— 粗筛结果就是最终判断，宁可少发。

## 存储

```
data/fishlib/
  index.json        [{id, file, at, tags[], album, bytes, dhash, verdict, skin, note}]
  20261111-221500-1.jpg
```

文件躺在磁盘上，索引只管元信息 —— 索引丢了还能扫目录重建（`file` 就是文件名）。

## 三个设计取舍

1. **标签是自由字符串**：群里说"来张猫"就该能搜到，不该逼用户先建标签体系。
2. **相册只有一层**：真要多级就用标签，别把相册做成树。
3. **去重阈值可调**：`0` = 只挡完全一样；`6` 挡转存/压缩；`10+` 会误杀同构图的图。

## 测试

```bash
python -m pytest tests -q     # 8 passed
```

覆盖：dHash 同图相同 / 非法输入返回 None、汉明距离与 `is_dup` / `nearest`、

`verify_with` 对异常吞掉、存储增删改查/标签/相册/分页/随机（注入 rng 保证可复现）。
